## 📦 Installation

Get up and running in a few short steps. No external Python packages or system dependencies required.

1. **Download the module** — Purchase and download the module from the Odoo Apps Store.
2. **Place into your addons path** — Extract the archive and copy the `sample_module` folder into your Odoo addons directory.
3. **Update the apps list & install** — Restart Odoo, refresh the apps list, search for the module, and click **Install**.

```bash
# Restart Odoo and update the apps list
$ sudo systemctl restart odoo
$ # Then in Odoo: Apps → Update Apps List → Install
```


## 🔧 Configuration

No complex setup required. Just enable the module and you're ready to go.

1. **Open Settings** — Navigate to the main Settings menu inside Odoo.
2. **Find the section** — Locate the module configuration block under Extra Tools.
3. **Enable & save** — Toggle the relevant options and click Save to apply.
4. **You're done!** — Refresh your browser and start using the module.
